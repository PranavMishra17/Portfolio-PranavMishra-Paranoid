I build the parts of an AI assistant that have to be right.

It stopped making things up. I rebuilt its working memory so fabrication is structurally impossible, enforced by tests rather than by hoping the model behaves.

It got faster. Email to text message went from about ninety seconds to three. The security code path went from three minutes to instant.

It got cheaper. I replaced per-message model calls in the rules engine with a matcher that just decides. Thirty percent less per user, and nearly every rule now gets made by talking to it.

It asks before it acts. Every action it wants to take gets sorted into one of five answers: stay quiet, tell him, check first, ask what he meant, or refuse.
